Refresh from this device

Refreshes run on GitHub, so this device needs a GitHub token to start one. You only do this once on each device.

  1. Make a new token on GitHub. Name it anything, like “Line Shop”, and set the expiration as long as GitHub allows.
  2. Under Repository access, choose Only select repositories and pick cfb-line-shop.
  3. Under Permissions, add Actions and set it to Read and write.
  4. Click Generate token, copy it, and paste it here.

The token is saved only in this browser, and it only has access to this site's GitHub Actions. Without one, you can still refresh on GitHub by pressing Run workflow.

    How to read the board
    Highlighter
    The better side of each bet when both books hang the same number. The small figure under it is how much better, in cents: −105 instead of −115 is 10¢.
    Better number
    When the books hang different lines, the better line gets the mark. A dashed box means that line costs more juice, so it's a trade-off. In football, half-points matter most around 3 and 7.
    Hold
    How far each book's two sides add up past 100%. Lower hold means a cheaper market to bet into.
    Middle
    Taking opposite sides at different books so that a narrow band of results wins both bets.
    Arb
    Both sides together pay out more than you stake whatever happens. Rare between these two books, and gone quickly when it shows up.
    Your card
    Tap a price to add that bet to your card; tap it again to take it off. After you place it in the sportsbook app, fix the odds or stake if they changed, press Mark placed, then copy your placed bets into Bet Ledger with Import from Line Shop. Your card is saved on the device you're using.
    Rotation
    The number to the left of each team is the sportsbook rotation number, the same one printed on betting sheets.

    This device can refresh the lines.

    Odds from The Odds API. Lines refresh at 8am, noon and 5pm Central, Monday through Friday, and whenever you press Refresh. An open page picks up each refresh on its own. Lines can trail the sportsbook apps, so confirm the number in the app before you bet.
